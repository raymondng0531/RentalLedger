# Rental Ledger - Project Roadmap

Version: 2.0

## Vision

Build a production-quality Flutter application for shared-household Central
Account management. Version 1.0 is a complete, polished, production-ready
release; later versions add quality-of-life, offline, and AI features.

------------------------------------------------------------------------

# Version 1.0 -- Production Release ✅ (in progress)

Version 1.0 includes ALL core production-ready features:

-   Authentication (Login, Register, Forgot Password, Social Sign-In, Logout)
-   House Management (Create, Join, Invite Code, Switch, Leave, Members)
-   Dashboard (Balance, Month In / Out, Pending, Recent Activity,
    Upcoming Bills)
-   Expenses (Submit, Edit, Delete, Receipt Upload, Approve, Reject,
    Reject Reason, Mark Paid, Timeline)
-   Treasurer Workflow (Approve, Reject, Reimburse, Direct Payment, Deposit)
-   Deposits
-   Direct Payments
-   Bills Management (Create, Edit, Delete, Reminder, Mark Paid, Recurring)
-   Upcoming Bills
-   History (Search, Filters, Grouping)
-   Reports (Charts, Category Breakdown, Monthly Trend)
-   Notifications (In-app, Real-time)
-   Settings (Language, Currency, Preferences)
-   Real-time Synchronization
-   Full UI Polish
-   Bug Fixes
-   Performance Optimization
-   PDF Export
-   Bills History Page
-   Better Report Filters
-   Better Analytics

Definition of Done: - Stable, no critical bugs - Consistent, polished UI -
Real-time sync without manual refresh - Production build passes

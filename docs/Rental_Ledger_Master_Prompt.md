## Project Overview

Rental Ledger is a **Central House Account Management System**, not an
expense-splitting app.

### Core Workflow

1.  User buys an item with personal money.
2.  Uploads the receipt.
3.  Creates an expense claim.
4.  Treasurer reviews it.
5.  Treasurer reimburses from the central account.
6.  Claim is marked as paid.

Also support direct payments from the central account.
